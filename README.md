# 🎮 坦克大战 (Tank Battle)

一个基于 HTML5 Canvas 的经典坦克大战游戏，使用原生 JavaScript 开发，无需任何外部依赖。

## ✨ 特性

- 🕹️ 经典坦克大战玩法
- 🤖 智能敌人 AI
- 💥 爆炸粒子效果
- 🧱 可破坏的砖墙和不可破坏的钢墙
- 🏆 基地保护机制
- 📱 支持键盘方向键和 WASD 双操控

## 🚀 快速开始

直接在浏览器中打开 `index.html` 即可开始游戏！

```bash
# 克隆仓库
git clone https://github.com/YOUR_USERNAME/tank-battle.git
cd tank-battle

# 在浏览器中打开
open index.html
```

## 🎯 操作说明

| 按键 | 功能 |
|------|------|
| `↑` / `W` | 向上移动 |
| `↓` / `S` | 向下移动 |
| `←` / `A` | 向左移动 |
| `→` / `D` | 向右移动 |
| `空格` | 射击 |
| `R` | 重新开始 |

## 📋 游戏规则

- 控制绿色坦克，消灭所有红色敌方坦克
- 保护黄色基地不被摧毁
- 你有 3 条生命
- 砖墙可以被子弹摧毁，钢墙不可摧毁
- 消灭所有敌人即可获胜！

## 🛠️ 技术栈

- HTML5 Canvas
- 原生 JavaScript (ES6+)
- CSS3
